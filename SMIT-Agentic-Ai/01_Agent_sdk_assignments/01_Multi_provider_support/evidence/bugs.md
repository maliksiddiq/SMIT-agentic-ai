| 1 | `runner_lab.py` lines 30-32: `demo_sync()` then `asyncio.run(demo_async())` / `asyncio.run(demo_streamed())` | Script HANGS (no output, process never exits). `Runner.run_sync()` internally creates AND closes its own asyncio event loop; the shared `AsyncOpenAI`/httpx client's transport stays bound to that now-closed loop, so the later `asyncio.run()` calls deadlock against it. | Reordered `__main__` to run the two async demos first (`asyncio.run(demo_async())`, `asyncio.run(demo_streamed())`) and call `demo_sync()` LAST, so `run_sync`'s self-closing loop is the final operation and nothing follows it. | Verified all three Runner modes work in isolation (`uv run python -c ...`), then reproduced the hang exactly by running `Runner.run_sync(...)` followed by `asyncio.run(...)` against the same client in one process. Also confirmed `Runner.run_streamed()` is NOT awaitable in openai-agents 0.20.0 (returns `RunResultStreaming` directly), so line 21's lack of `await` is correct.
