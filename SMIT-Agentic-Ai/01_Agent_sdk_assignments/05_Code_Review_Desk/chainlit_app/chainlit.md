# Code Review Desk

## Professional code review, in one pass

Paste a complete unified diff to run three focused reviews in parallel:

| Specialist | Focus |
|---|---|
| **Security** | Vulnerabilities, injection, secrets, and unsafe patterns |
| **Tests** | Coverage, regressions, and edge cases |
| **Style** | Readability, consistency, and maintainability |

Your report includes live reviewer progress, severity-ranked findings,
remediation guidance for critical issues, and compact execution metrics.

### Getting the best review

Use the complete output of `git diff`, including file paths and context lines.
You can submit another diff in the same conversation to compare changes.
